# oblivion-remaster-bsa-backup
Un script de backup des fichiers d'origine pour le mod oblivion remastered 0.6
S'utilise en complément du mod [Frenchyblivion - Patch FR](https://www.nexusmods.com/oblivionremastered/mods/1131).

# Pour l'installation

## 1. Téléchargez le mod [Frenchyblivion - Patch FR](https://www.nexusmods.com/oblivionremastered/mods/1131) :
https://www.nexusmods.com/oblivionremastered/mods/1131
## 2. Téléchargez le script backup.bat

## 3. Copiez le script à côté du dossier OblivionRemastered

## 4. Lancez le script

## 5. Faites l'extraction du dossier OblivionRemastered de Frenchyblivion - Patch FR sur le dossier OblivionRemastered


**Si vous avez bien lancé le script la question de remplacement de fichier n'est pas posé par le système.**
**Si le système pose la question, c'est que vous avez pas lancé le script au bon emplacement.**

## 6. Ajoutez les lignes :
FrenchyBlivionAltar.esp
FrenchyBlivionDLC.esp
FrenchyBlivionVanilla.esp

À la fin du fichier "OblivionRemastered\Content\Dev\ObvData\Data\Plugins.txt"

## 6. Optionnel. Téléchargez et installez le mod [Silent Protagonist](https://www.nexusmods.com/oblivionremastered/mods/180)
https://www.nexusmods.com/oblivionremastered/mods/180

Pour pas vous faire exploser les oreilles quand vous prenez des dégâts ou faites une attaque puissante.
